# Versioning

Combat Connect follows Semantic Versioning.

Format:

MAJOR.MINOR.PATCH

Example:

1.0.0

1.1.0

1.2.5

2.0.0

---



# Release Policy

PATCH

- Bug fixes
- Performance improvements

MINOR

- New features
- Enhancements

MAJOR

- Breaking architectural changes
